## 1. Filtragem das amostras

O primeiro passo deste pipeline de metabarcoding é a filtragem (<a href="https://www.drive5.com/usearch/manual/cmd_fastq_filter.html" target="_blank" rel="noopener noreferrer">manual</a>) das amostras:

Corra de acordo com a sua amostra baixada:

```bash
./usearch -fastq_filter sample7_1_mergepear.fastq.assembled.fastq -fastq_maxee 1 -fastq_minlen 300 -fastq_truncqual 25 -fastaout sample7.fasta -relabel araca_sample7 >& log_sample7
```

```bash
./usearch -fastq_filter sample9_4_mergepear.fastq.assembled.fastq -fastq_maxee 1 -fastq_minlen 300 -fastq_truncqual 25 -fastaout sample9.fasta -relabel araca_sample9 >& log_sample9
```

<a id="remocao-de-quimeras-e-identificacao-de-otus"></a>

## Remoção de quimeras e identificação de OTUs

A terceira etapa é remover (<a href="https://www.drive5.com/usearch/manual/cmd_cluster_otus.html" target="_blank" rel="noopener noreferrer">manual</a>) sequências quiméricas e identificar as sequências consideradas idênticas (por convenção, nesta etapa se usa identidade mínima de 97%) e que, eventualmente, podem ser consideradas uma unidade taxonômica organizacional (OTU).

```bash
./usearch -cluster_otus sampleuniq[numero amostra].fasta -otus otussample[numero amostra].fa -uparseout out[numero amostra].txt -relabel bentosOTU >& logcluster[numero amostra]
```

Nesta linha de comando geramos um arquivo final das nossas sequências por amostra e um arquivo .txt que contém as informações de identificação (<a href="https://www.drive5.com/usearch/manual/opt_uparseout.html" target="_blank" rel="noopener noreferrer">manual</a>) de cada sequência.

## Preparando a base de dados de referência

Na próxima etapa, iremos preparar a nossa base de dados para a referência. Usearch monta uma base de dados a partir de um fasta extraído dos arquivos do formato genbank. Esse arquivo fasta já existe e deve ser baixado do servidor:

```bash
scp -P 2205 deadg@143.107.247.17:/home/deadg/pratica9a/ref_uniques.fa ./
```

```bash
scp -P 2205 deadg@143.107.247.17:/home/deadg/pratica9a/unique.tc ./
```

Senha: `D4!42026`

O arquivo fasta contém a base de referência e o arquivo .tc contém os scores por nível taxonômico. O score mede o quão completo está cada nível em relação ao nível taxonômico superior.

```bash
./usearch -makeudb_utax ref_uniques.fa -taxconfsin unique.tc  -output ref.udb
```

Para visualizar a distribuição dos taxa da sua referência, digite a seguinte linha de comando:

```bash
./usearch -tax_stats ref_uniques.fa -log stats.txt
```
